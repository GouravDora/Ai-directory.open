# Contributing to AI Directory

First off, thank you for considering contributing to AI Directory! It's people like you that make open source such a great community.

## How Can I Contribute?

### Reporting Bugs
- Check if the bug has already been reported in the Issues tab.
- If not, open a new issue. Clearly describe the bug and how to reproduce it.

### Suggesting Enhancements
- Open a new issue and describe the feature you want to see. Explain why it would be useful.

### Your First Code Contribution
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/AmazingFeature`).
3. Make your changes.
4. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
5. Push to the branch (`git push origin feature/AmazingFeature`).
6. Open a Pull Request.

## Pull Request Guidelines
- Ensure your code passes the lint checks (`npm run lint`).
- Keep your PRs focused on a single feature or bug fix.
- Write a clear description of what you changed.

Thank you for contributing!
